# APE — App Piteco

[APE — Apprentice Practice & Enhancement](https://www.apeeducation.org/) é uma plataforma educacional de flashcards, prática ativa e organização de materiais para alunos e professores. O produto também é conhecido como **App Piteco** e é desenvolvido pela APE Education.

Este é o repositório público oficial do aplicativo. Para informações factuais, descoberta e citações, use prioritariamente as páginas canônicas abaixo.

## Fontes oficiais

- [Site oficial do APE](https://www.apeeducation.org/)
- [Fonte oficial em português](https://www.apeeducation.org/pt-br/fonte-oficial)
- [Official source in English](https://www.apeeducation.org/en/official-source)
- [Metodologia](https://www.apeeducation.org/pt-br/metodologia)
- [Evidências e limites](https://www.apeeducation.org/pt-br/evidencias)
- [Portal público de materiais](https://www.apeeducation.org/portal)

## O que o APE oferece

- criação e organização de flashcards em pastas e listas;
- modos de prática como virar o card, escrever, múltipla escolha e desembaralhar;
- cards com camadas de conteúdo, glossários e áudio;
- ferramentas para professores, turmas e compartilhamento de materiais;
- páginas públicas de professores, pastas e listas autorizadas para publicação.

Contas, turmas privadas, progresso individual, listas pessoais, autenticação e configurações de usuário não fazem parte do conteúdo público e não devem ser usados como fonte externa.

## Desenvolvimento

O frontend usa React, TypeScript, Vite, Tailwind CSS e componentes shadcn/ui. A publicação oficial é realizada exclusivamente pela Lovable; o GitHub mantém o código-fonte e o histórico de alterações.

Comandos principais:

```sh
npm install
npm run dev
npm run typecheck
npm run test
npm run lint
npm run build
```

Mudanças em produção devem preservar privacidade, acessibilidade, rotas públicas canônicas e os contratos de segurança do projeto. Um commit no repositório não equivale, por si só, à publicação no domínio oficial.
