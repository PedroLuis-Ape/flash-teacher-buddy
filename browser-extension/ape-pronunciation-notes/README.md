# APE Pronúncia e Notas

Extensão Manifest V3 do APE — App Piteco.

## Preset inicial

- modo de idioma: manual;
- idioma principal: `en-US`;
- voz preferida: Google;
- velocidade: `0.92`;
- tom: `0.95`.

## Funções

- mini barra ao selecionar palavras ou frases;
- pronúncia por `chrome.tts`;
- menu de contexto para ouvir ou salvar;
- notas locais com reprodução e exclusão;
- nenhum conteúdo é enviado ao Supabase.

## Publicação

O ZIP gerado pelo workflow `Browser Extension Package` deve ser enviado à Chrome Web Store e, opcionalmente, ao Microsoft Edge Add-ons. Depois da aprovação, adicione as URLs em `public/extensao/store-config.json`.
