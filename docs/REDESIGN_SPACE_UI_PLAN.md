# Space UI Redesign — reversible implementation

Branch: `redesign/space-ui-v1`

This branch contains the visual redesign inspired by the approved purple cosmic Piteco concept.

## Safety rules

- Nothing in this branch changes `main` automatically.
- No database migration is included.
- Supabase contracts, authentication, study engine logic and persisted user data remain unchanged.
- The branch can be deleted at any time to abandon the redesign.
- Merge must happen only after desktop/mobile review and CI validation.

## Delivery waves

1. Global visual tokens, cosmic background and shared surfaces.
2. Private navigation shell and responsive navigation chrome.
3. Home/dashboard hierarchy and Piteco hero treatment.
4. Library, lists, folders and classroom surfaces.
5. Study modes and study-session chrome.
6. Profile, goals, store, kingdom and teacher dashboard.
7. Accessibility, reduced motion, performance and responsive QA.

## Rollback

Before merge: close the pull request and delete this branch.

After merge: revert the merge commit generated by GitHub. The redesign is intentionally isolated so rollback does not require database restoration.
