# Galaxy scene expansion

The Galaxy palette now uses adaptive decorative layers.

- Full: nebula, dust, two galaxies, planet, moon, stars and comets.
- Balanced: static nebula, one galaxy, one planet, fewer stars and one occasional comet.
- Static: no new scene assets or animations.

The implementation uses transform and opacity, keeps pointer events disabled, pauses when the tab is hidden and preserves the lightweight mobile layout.
