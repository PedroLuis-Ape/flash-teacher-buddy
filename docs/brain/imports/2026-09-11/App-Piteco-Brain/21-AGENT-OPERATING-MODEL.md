# Agent Operating Model

## Limite
No máximo ~5–6 agentes simultâneos.

## Agent 01 — Supervisor
- ownership;
- dependências;
- prioridade;
- revisão;
- CURRENT STATE;
- handoff.

## Agent 02 — Core/Data
- sessions;
- autosave;
- presets;
- recovery;
- Supabase de estudo.

## Agent 03 — Games/Study
- Flip
- Write
- Rewrite
- Multiple Choice
- Unscramble
- Mixed
- Mastery
- demais modos.

## Agent 04 — UI/Mobile
- layout;
- navigation;
- dialogs/sheets;
- keyboard;
- responsive;
- motion foundations.

## Agent 05 — Content Systems
- glossário;
- word_hints;
- Smart Import;
- import/export;
- semantic review.

## Agent 06 — QA / Red Team
- browser real;
- screenshots;
- refresh/back;
- double click/tap;
- slow network;
- mobile;
- regressões;
- não confia no relatório do implementador.

## Cadeia
Especialista → Supervisor → QA → aprovado.

## Ownership
Registrar owner antes de editar arquivo compartilhado.

## Ondas
1. estabilidade
2. study/games
3. import/content
4. UI/motion
5. finalização.

Agente é papel, não tarefa eterna; pode ser rotacionado.
