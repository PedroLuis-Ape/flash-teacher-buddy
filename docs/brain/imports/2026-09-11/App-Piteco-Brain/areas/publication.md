# Area — Publication

## Frontend
**[VERIFICADO-REPO]**
A publicação oficial do frontend é feita pela Lovable.

GitHub mantém:
- código;
- histórico;
- branches/PRs;
- testes;
- documentação.

Um commit em `main` não prova publicação no domínio oficial.

## Regra para agentes
Não:
- fazer deploy automático;
- fazer rollback remoto automático;
- aplicar migration remota automaticamente;
- publicar extensão automaticamente.

Preparar, testar e documentar; publicação precisa de autorização/fluxo apropriado.

## Public web
Quando alterar páginas públicas:
- validar canonical;
- hreflang;
- robots;
- sitemap;
- JSON-LD;
- llms.txt;
- prerender;
- privacidade/autoria.

## Lovable
Para alteração visual:
- usar preview;
- screenshot antes/depois;
- testar vários viewports;
- publicar só após gates e QA.
