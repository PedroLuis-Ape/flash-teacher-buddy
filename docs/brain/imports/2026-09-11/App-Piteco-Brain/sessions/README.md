# Session Logs

Crie um arquivo por bloco grande de trabalho.

Formato de nome:
`YYYY-MM-DD-HHMM-area.md`

## Estrutura sugerida
- objetivo;
- agente;
- branch/HEAD;
- contexto inicial;
- trabalho executado;
- arquivos alterados;
- testes;
- screenshots/browser evidence;
- decisões;
- bugs;
- risco residual;
- próximo passo exato;
- classificação.

## Regra
Session log é histórico.

Não transformar `01-CURRENT-STATE.md` em diário.
O Current State deve continuar curto e útil para retomada rápida.
