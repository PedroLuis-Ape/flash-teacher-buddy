# Resumo técnico — Etapa 6

A implementação usa detecção de viewport, movimento reduzido, atualização lenta, ponteiro, economia de dados, memória e núcleos lógicos. O resultado é exposto em `data-galaxy-motion` e consumido por CSS específico. A animação do cometa usa Web Animations API com temporizadores canceláveis e observação de visibilidade da página.
