# Exportação dos pacotes Piteco

Exportação preparada em 21 de junho de 2026 para redesign.

## Conteúdo

- `01_pacotes_ativos`: Prime, Vampiro e Zombie.
- `02_pacotes_extras`: Astronauta e Chad/Gold nas versões finais encontradas.
- `03_versoes_antigas`: versões anteriores do Astronauta, Gold e Scientist.
- `manifesto.csv`: relação entre cada arquivo exportado e o caminho original no repositório.

## Observação técnica

Alguns arquivos antigos tinham extensão `.png`, mas o conteúdo interno é JPEG. Na exportação eles receberam extensão `.jpg`, sem qualquer alteração visual ou recompressão.

Os arquivos foram reunidos usando os blobs originais do repositório. Nenhuma imagem foi editada, redimensionada ou convertida.
