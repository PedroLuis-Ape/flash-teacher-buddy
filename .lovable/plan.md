

## Plan: Glossary-Aware Import System

### Summary
Adapt the bulk import flow to support the new two-section format (`=== GLOSSÁRIO GLOBAL ===` + `=== CARDS ===`) generated by LLMs, while maintaining full backward compatibility.

### Changes

**1. Update `AI_HELPER_PROMPT` in `src/lib/bulkImport.ts`**
- Replace the existing prompt with the new version that instructs the LLM to generate two sections: glossary + cards.
- Include deduplication rules, relevance guidance, and scale instructions for the glossary.

**2. Add section-aware parser in `src/lib/bulkImport.ts`**
- New exported function: `parseGlossaryAndCards(input: string)` that returns `{ glossaryLines: GlossaryParsed[], cards: FlashcardPair[] }`.
- Detection logic: look for `=== GLOSSÁRIO GLOBAL ===` and `=== CARDS ===` markers (case-insensitive, trimmed).
- If no markers found, treat entire input as cards (backward compat).
- Glossary parser: split each line by `/`, trim both sides, skip empty/invalid lines.
- Cards parser: reuse existing `parsePastedFlashcards()` on the cards section.

**3. Add glossary deduplication utility in `src/lib/bulkImport.ts`**
- New function: `deduplicateGlossary(parsed, existingGlossary)` — compares `original_text + translated_text` (lowercased, trimmed) to skip duplicates.

**4. Update `BulkImportDialog.tsx`**
- On parse: call `parseGlossaryAndCards()` instead of `parsePastedFlashcards()` directly.
- Show glossary preview section (count of new entries, duplicates skipped).
- On import: first insert new glossary entries into `list_glossary` via the existing hook/supabase call, then insert cards as before.
- Update the AI helper UI text to reflect the new two-section format.

**5. No other files changed**
- Study engine, favorites, tooltips, turmas — all untouched.
- `list_glossary` table already exists with the correct schema.

### Backward Compatibility
- If pasted content has no `=== GLOSSÁRIO GLOBAL ===` marker, the parser returns an empty glossary array and processes everything as cards — identical to current behavior.

### Technical Details

```text
parseGlossaryAndCards(input)
  ├── detect markers
  │   ├── found both → split into glossary section + cards section
  │   ├── found only CARDS → everything after marker = cards, no glossary
  │   └── no markers → entire input = cards (legacy)
  ├── glossary section → line-by-line split by "/"
  └── cards section → existing parsePastedFlashcards()
```

Import flow in BulkImportDialog:
1. Parse → show preview (glossary count + card count)
2. User confirms → insert glossary (deduplicated) → insert cards (deduplicated)
3. Invalidate both `list-glossary` and flashcards queries
